# 2026-11-22

_Environment: GitHub Codespace on Alpine 3.23, 2 vCPU, 8 GB, no Docker; `sudo` available, which is
what made the root-path test below possible._

## Summary

B2 from the Phase 1 review: the control-plane image now starts as root only long enough to take
ownership of the platform-mounted volume, then re-execs the supervisor as an unprivileged uid.
The `RAILWAY_RUN_UID=0` workaround is gone from code and docs.

## Shipped

| PR | Merge | What |
|----|-------|------|
| [#6](https://github.com/brezzy1337/provider-upjet-railway/pull/6) | this PR | `drop_privileges_if_root` as the supervisor's first step: `chown -R` of the state root, `CP_HOME` and `/terraform` to `CP_RUN_UID:CP_RUN_GID` (default 65532, recursive only when the owner differs), `chmod 700`, then `exec su-exec` of the same script with the same arguments and environment. Dockerfile installs `su-exec`, drops `USER`, sets `CP_RUN_UID`. `CP_STAY_ROOT=true` opts out with a warning. Error text and docs no longer mention `RAILWAY_RUN_UID` |

## Verified

Native harness, three boots on 2026-11-22. The state root was first chowned to `root:root` mode 755
to imitate a Railway mount.

| Scenario | Result |
|----------|--------|
| Started as root (`sudo`) with `CP_RUN_UID=1000` on the root-owned state root | 18 s to provider ready; log shows the chown of `state/` and `home/`; afterwards the root is `1000` mode 700, `pki/ca.key` and `etcd/` owned by 1000; **every process including the supervisor runs as uid 1000**; 21/21 |
| Unprivileged restart on that state | 12 s; no root-path log lines; identity check passes; 21/21 |
| Started as root with `CP_STAY_ROOT=true` | boots in 12 s as root with the warning line |

No leftover processes after any scenario. Not verified: the Docker image build and Railway.

## Decided

- The chown is recursive only when the state root's owner differs from `CP_RUN_UID`, so a healthy
  boot pays one `stat`; `CP_FORCE_CHOWN=true` forces it (for a volume with mixed ownership).
- `su-exec` rather than `setpriv` or `gosu`: it is a 10 KB Alpine package and preserves the
  environment, which the re-exec relies on.
- `HOME` is set to `CP_HOME` for the unprivileged process so nothing tries to write under `/root`.

## Found

Nothing new. The B2 landmine recorded in the Phase 1 review (root-owned files left by an interim
root-run deployment) is handled by the recursive chown path.
